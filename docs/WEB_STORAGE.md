# Browser storage\n\nThe GitHub Pages version uses IndexedDB in the user's browser. It stores client and invoice data locally in the browser profile and does not upload invoices to a server. Data is not automatically shared between browsers or devices. Clearing site data, using private browsing, or changing devices can make records unavailable. Use Export backup regularly and store the exported JSON securely. The desktop edition will use SQLite in the application data directory.\n\nThis is a local single-user tool, not a multi-user cloud service. A database backup includes client addresses, invoice content, and payment references; treat it as confidential.
